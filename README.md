# parking_lot_v1

Локальный инженерный прототип для проверки геометрии парковочных модулей на произвольном плоском участке. Проект не использует npm, Vite, React, TypeScript, сборщики, CDN или внешние библиотеки.

## Как открыть

1. Скачайте или откройте папку проекта.
2. Откройте файл `index.html` напрямую в современном браузере двойным кликом или через меню браузера **File → Open File**.
3. Измените параметры машино-места, проезда или шага сетки и нажмите **«Пересчитать»**.

Все вычисления выполняются локально в браузере в `app.js`.

## Что делает v1

- Задает тестовый невыпуклый участок в метрах.
- Строит растровую сетку с заданным шагом внутри участка.
- Размещает парковочные модули 90° только с углом 0°:
  - тип А: один ряд машино-мест + проезд;
  - тип Б: два ряда машино-мест + общий проезд.
- Сначала пытается разместить двухрядный модуль, затем однорядный.
- Не допускает пересечение машино-мест между собой.
- Не допускает пересечение проезда с машино-местами.
- Разрешает наложение проездов друг на друга.
- Рисует SVG-план участка, координатную сетку, машино-места и проезды.
- Считает площадь проездов по уникальным ячейкам сетки, а не суммой прямоугольников.

## Ограничения v1

- Проверка геометрии растровая, а не через точные polygon boolean-операции.
- Точность результата зависит от параметра «шаг сетки».
- Используется только один тестовый участок, заданный в коде.
- Используется только ориентация 0° для модулей 90°.
- Нет поддержки углов 45° и 60°.
- Нет препятствий, въездов, правил связности проездов и нормативных типов мест.
- Подбор детерминированный и жадный: проход полосами без сложного перебора вариантов.
